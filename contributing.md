# Contribution Guidelines

Please note that this project is released with a [Contributor Code of Conduct](https://github.com/sindresorhus/awesome/blob/main/code-of-conduct.md). By participating in this project you agree to abide by its terms.

## What belongs here

A skill belongs here if it is fun: it has a personality, a gimmick, or produces something delightful (images, motion, video, characters, games). Plain productivity or coding-convention skills belong in the general lists linked under Related Lists.

Each entry must:

- Be an agent skill (a `SKILL.md` or a pack of them) usable in at least one agent such as Claude Code, Codex or Cursor.
- Have a README that explains what it does and how to install it.
- Not be archived or abandoned.

## How to add an entry

- Search the list first to avoid duplicates.
- Add one entry per pull request.
- Add it to both `README.md` and `README.zh-CN.md`, in alphabetical order within the matching section.
- Use the format `- [name](link) - Description.` The description starts with an uppercase letter (English) and ends with a period.
- Do not add star counts or badges to entries.
- Use a pull request title like `Add skill-name`.

Thank you for your suggestions!
